# 🏦 Sistema-de-Cadastro-e-Analise-Financeira-de-Clientes

📖 Sobre o projeto

O Credit Analysis Simulator é uma aplicação desenvolvida em Python com o objetivo de simular parte do processo de análise financeira realizado por instituições bancárias durante a solicitação de crédito.

O sistema realiza o cadastro de um cliente, analisa sua renda, simula um empréstimo com diferentes taxas de juros, verifica critérios básicos de aprovação e concede um benefício aleatório ao usuário.

Este projeto foi desenvolvido como parte dos meus estudos em Python, colocando em prática conceitos fundamentais da linguagem através de um problema baseado em um cenário real.

🚀 Funcionalidades
Cadastro completo de clientes
Cálculo automático da renda anual
Classificação da renda do cliente
Simulação de empréstimos
Aplicação de taxas de juros conforme o número de parcelas
Análise de aprovação do crédito
Sorteio de benefícios utilizando a biblioteca random
Geração de um relatório final da análise
🛠 Tecnologias utilizadas
Python 3
Biblioteca Random

🎯 Objetivo

Mais do que desenvolver um simples exercício, este projeto busca simular uma situação próxima da realidade encontrada em sistemas bancários, aplicando regras de negócio para análise de clientes e tomada de decisão.

Além da implementação das funcionalidades, o projeto contribuiu para o fortalecimento da lógica de programação e da capacidade de transformar requisitos em código.
